# DataTrace

**让每一次法规变化，都能追溯到来源。**

DataTrace 是面向跨境产品、隐私与合规团队的法规追踪工作台，以香港和新加坡的数据保护、金融与电信规则为主要内容。它把分散的官方文书、条款摘要、修订事件与来源状态组织在同一个浏览路径中，帮助使用者从“发生了什么”走到“依据在哪里、接下来应核查什么”。公开站点提供可直接体验的静态演示，仓库同时保留完整服务端实现。

## 适合谁使用

- 隐私与合规人员：按法域和主题查找法规，回到官方原文核验。
- 跨境产品与业务团队：了解关联行业的规则变化，为内部讨论准备依据。
- 开发与研究人员：体验从来源采集、数据保存到静态发布的完整链路。

## 8 个功能模块

### 01 · 法规雷达与动态概览
**演示可用**

集中呈现法规、结构化义务和历史事件的数量，以及最近的规则更新。先看到内容覆盖与近期变化，再进入法规库或更新线。

**你能得到什么：** 得到一张可继续展开的内容概览，帮助决定先查看哪条变化。

### 02 · 多维法规库
**演示可用**

按法域、行业、主题、文书类型和关键词组合筛选法规。筛选条件保存在链接中，便于回访或向同事分享同一组检索结果。

**你能得到什么：** 把宽泛的研究问题收敛为可阅读的相关文书列表。

### 03 · 结构化条款与官方原文
**演示可用**

详情页展示发布机关、生效与版本日期、来源核验日期，以及已整理的条文摘要和关键词。每条法规提供官方来源入口；尚未拆解的文书会明确提示。

**你能得到什么：** 先掌握文书的结构和重点，再带着具体问题核查原文。

### 04 · 规则更新线
**演示可用**

按时间浏览生效、修订和指引发布事件，可按法域筛选。事件展示法域、行业标签和官方来源；已发布历史数据会持续保留，当前列表每次最多显示 100 条。

**你能得到什么：** 看到一项规则如何变化，而不只是孤立地阅读最新标题。

### 05 · 来源状态与覆盖提示
**演示可用**

逐个来源区分采集成功、来源不可用、解析无匹配及尚未检查，并展示可取得的最近成功信息。来源异常时仍可浏览已有历史数据。

**你能得到什么：** 知道“没有新条目”背后的原因，判断是否需要手动补查。

### 06 · 采集、审校与静态发布
**已实现 / 演示自动化**

服务端提供官方源采集、重复识别和待审校记录，命令行支持批准、拒绝与编辑。每日工作流会采集香港、新加坡来源，以演示自动收录方式生成并发布静态快照。

**你能得到什么：** 维护者可以追踪内容来源与发布过程；自动收录会与人工审校区分。

### 07 · 三语阅读与分享入口
**演示可用**

仓库首页及产品界面支持简体中文、繁體中文和 English，保留语言偏好。法规详情支持直接链接，手机布局也可浏览、筛选和阅读。

**你能得到什么：** 使用同一套资料进行跨语言协作；官方文书保持原文。

### 08 · 订阅与邮件简报
**服务端已实现 / 邮件待启用**

服务端已有法域偏好、邮箱双重确认、订阅管理、退订、派发队列与发送回执逻辑。公开静态站仅展示订阅和简报体验，真实订阅写入、每日邮件及提醒尚未启用。

**你能得到什么：** 为后续服务化保留完整路径；开通前需要独立后端、发信配置及渠道验收。

## 如何使用

1. 从法规雷达了解当前内容覆盖和最近变化。
2. 进入法规库，按目标法域、行业或主题缩小范围。
3. 打开详情，阅读结构化摘要、核验日期并访问官方来源。
4. 沿更新线核对相关事件；遇到缺失时先查看来源状态。
5. 需要持续触达时，先了解订阅渠道的启用条件，再部署服务端。

## 当前完成情况

- 公开 GitHub Pages 静态演示已可访问；内容会随现有每日采集与构建流程更新。
- 服务端采用 Node.js 与 SQLite；法规、条款、更新和订阅数据由应用保存。
- 三语界面已覆盖主要阅读路径；静态站不接收真实订阅，邮件渠道保持未启用。

## 快速开始

直接查看在线演示无需安装。运行完整本地应用需要 Node.js 22.13+（建议使用 22.x 最新补丁版）；无第三方运行时依赖。在仓库根目录执行以下命令。

```bash
cd data-trace
npm start
# http://localhost:3000

# 检查与静态站构建
npm run check
npm test
npm run build:demo
```

## 使用边界

- 2026-08-09 是种子内容核验基线，不代表全部法规今天已重新核验。具体内容应以来源和对应日期为准。
- 每日演示自动收录不等于人工法律审校，也不保证覆盖所有变更；法规摘要用于研究导航，不替代官方原文与专业判断。
- 界面语言切换保留官方原文；公开静态产物不含订阅者和发信凭据。
