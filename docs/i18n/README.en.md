# DataTrace

**Trace every regulatory shift to its source.**

Regulatory tracking for cross-border product and privacy teams in Hong Kong and Singapore. Connect the regulation library, change timeline and collection status to official sources.

[Live entry](https://2432antony-13.github.io/data-trace/) · [Issues](https://github.com/2432antony-13/data-trace/issues) · [Docs](../../docs/README.md)

## Current status

The public static demo is available. Daily collection and deployment are connected; failed sources and empty results are reported separately. Email subscriptions and briefing dispatch remain inactive.

## Quick start

Node.js 22.5+; no runtime dependency installation required.

```bash
cd data-trace
npm start
# http://localhost:3000
npm run check
npm test
npm run build:demo
```

## Capabilities and scope

Search and filter regulations; inspect versions and sources; track jurisdiction changes; inspect source collection status.

Interface translations do not replace official text. 2026-08-09 is the seed-content verification baseline, not evidence that all current law has been reviewed today.

[Source](../../data-trace/) · [Docs](../../docs/README.md)

Repository homepages and usage entry points are available in three languages. Product interface coverage is tracked separately; documentation translation does not imply full product localization.
