# DataTrace

**讓每一次法規變化，都能追溯到來源。**

DataTrace 是面向跨境產品、隱私與合規團隊的法規追蹤工作台，以香港和新加坡的資料保護、金融與電信規則為主要內容。它把分散的官方文書、條款摘要、修訂事件與來源狀態組織在同一個瀏覽路徑中，幫助使用者從“發生了什麼”走到“依據在哪裡、接下來應核查什麼”。公開站點提供可直接體驗的靜態示範，儲存庫同時保留完整伺服器端實現。

## 適合誰使用

- 隱私與合規人員：按法域和主題查詢法規，回到官方原文核驗。
- 跨境產品與業務團隊：瞭解關聯行業的規則變化，為內部討論準備依據。
- 開發與研究人員：體驗從來源採集、資料儲存到靜態釋出的完整鏈路。

## 8 個功能模組

### 01 · 法規雷達與動態概覽
**示範可用**

集中呈現法規、結構化義務和歷史事件的數量，以及最近的規則更新。先看到內容覆蓋與近期變化，再進入法規庫或更新線。

**你能得到什麼：** 得到一張可繼續展開的內容概覽，幫助決定先檢視哪條變化。

### 02 · 多維法規庫
**示範可用**

按法域、行業、主題、文書類型和關鍵字組合篩選法規。篩選條件儲存在連結中，便於回訪或向同事分享同一組檢索結果。

**你能得到什麼：** 把寬泛的研究問題收斂為可閱讀的相關文書列表。

### 03 · 結構化條款與官方原文
**示範可用**

詳情頁展示發布機關、生效與版本日期、來源核驗日期，以及已整理的條文摘要和關鍵詞。每條法規提供官方來源入口；尚未拆解的文書會明確提示。

**你能得到什麼：** 先掌握文書的結構和重點，再帶著具體問題核查原文。

### 04 · 規則更新線
**示範可用**

按時間瀏覽生效、修訂和指引發布事件，可按法域篩選。事件展示法域、行業標籤和官方來源；已釋出的歷史資料會持續保留，目前列表每次最多顯示 100 條。

**你能得到什麼：** 看到一項規則如何變化，而不只是孤立地閱讀最新標題。

### 05 · 來源狀態與覆蓋提示
**示範可用**

逐個來源區分採集成功、來源不可用、解析無匹配及尚未檢查，並展示可取得的最近成功資訊。來源異常時仍可瀏覽已有歷史資料。

**你能得到什麼：** 知道“沒有新條目”背後的原因，判斷是否需要手動補查。

### 06 · 採集、審校與靜態釋出
**已實現 / 示範自動化**

伺服器端提供官方源採集、重複識別和待審校記錄，命令列支援批准、拒絕與編輯。每日工作流程會採集香港、新加坡來源，以示範自動收錄方式生成並發布靜態快照。

**你能得到什麼：** 維護者可以追蹤內容來源與釋出過程；自動收錄會與人工審校區分。

### 07 · 三語閱讀與分享入口
**示範可用**

儲存庫首頁及產品介面支援簡體中文、繁體中文和 English，保留語言偏好。法規詳情支援直接連結，手機佈局也可瀏覽、篩選和閱讀。

**你能得到什麼：** 使用同一套資料進行跨語言協作；官方文書保持原文。

### 08 · 訂閱與郵件簡報
**伺服器端已實現 / 郵件待啟用**

伺服器端已有法域偏好、郵箱雙重確認、訂閱管理、退訂、派發佇列與傳送回執邏輯。公開靜態站僅展示訂閱和簡報體驗，真實訂閱寫入、每日郵件及提醒尚未啟用。

**你能得到什麼：** 為後續服務化保留完整路徑；開通前需要獨立後端、發信設定及渠道驗收。

## 如何使用

1. 從法規雷達瞭解目前內容覆蓋和最近變化。
2. 進入法規庫，按目標法域、行業或主題縮小範圍。
3. 開啟詳情，閱讀結構化摘要、核驗日期並訪問官方來源。
4. 沿更新線核對相關事件；遇到缺失時先檢視來源狀態。
5. 需要持續觸達時，先了解訂閱渠道的啟用條件，再部署伺服器端。

## 目前完成情況

- 公開 GitHub Pages 靜態示範已可訪問；內容會隨現有每日採集與建置流程更新。
- 伺服器端採用 Node.js 與 SQLite；法規、條款、更新和訂閱資料由應用儲存。
- 三語介面已覆蓋主要閱讀路徑；靜態站不接收真實訂閱，郵件渠道保持未啟用。

## 快速開始

直接檢視線上示範無需安裝。執行完整本機應用需要 Node.js 22.13+（建議使用 22.x 最新修補版本）；無第三方執行階段相依套件。在儲存庫根目錄執行以下命令。

```bash
cd data-trace
npm start
# http://localhost:3000

# 檢查與靜態站建置
npm run check
npm test
npm run build:demo
```

## 使用邊界

- 2026-08-09 是種子內容核驗基線，不代表全部法規今天已重新核驗。具體內容應以來源和對應日期為準。
- 每日示範自動收錄不等於人工法律審校，也不保證覆蓋所有變更；法規摘要用於研究導航，不替代官方原文與專業判斷。
- 介面語言切換保留官方原文；公開靜態產物不含訂閱者和發信憑據。
